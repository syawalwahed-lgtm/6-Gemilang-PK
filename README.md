# Misi Juara Sihat! — Pendidikan Kesihatan Tahun 6

Permainan pembelajaran responsif dalam Bahasa Melayu untuk topik **Pemakanan Sihat dan Selamat**.

## Kandungan
- Nota infografik ringkas.
- 20 soalan objektif dan maklum balas jawapan.
- Perlumbaan kereta arcade dengan kemajuan litar.
- Bintang, papan skor, paparan kemenangan dan konfeti.
- Kesan bunyi melalui Web Audio API.
- Suara melalui Web Speech API jika pelayar/peranti menyediakan suara Bahasa Melayu.
- Mesra telefon, tablet dan komputer.

## Cara guna
1. Ekstrak fail ZIP.
2. Buka `index.html` dengan pelayar moden (Chrome, Edge, Safari atau Firefox).
3. Tekan **Bunyi: ON** untuk audio. Suara Bahasa Melayu bergantung pada sokongan suara yang tersedia pada peranti.

## Terbitkan di GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `pk-tahun6-arcade`.
2. Muat naik `index.html` dan `README.md` ke akar repositori.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
6. Selepas penerbitan selesai, GitHub akan memaparkan URL laman Pages dalam bahagian Pages.

Saya tidak menerbitkan ke akaun GitHub pengguna secara automatik; muat naik perlu dibuat menggunakan akaun pemilik repositori.

- SP 1.3.2: Memahami faedah pengambilan makanan segar.
- SP 1.3.3: Memahami kesan pengambilan makanan yang diproses dan makanan segera.
